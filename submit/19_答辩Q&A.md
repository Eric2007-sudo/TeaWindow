# 答辩 / 评审 Q&A 预演（AI4Climate · 梅坞采候 TeaWindow）

> 用法：路演与答辩前过一遍。回答遵循"先结论、再证据、后边界"，不夸大。

## 定位与创新
**Q1. 气象部门已经在做预警，你们的增量是什么？**
A：我们不重复官方预警，也不做全区替代。增量在**地块级、复合、可执行**三件事：
① 把「倒春寒×高温×干旱×物候」合成一个复合风险 R，而不是单一阈值；
② 落到**地块/坡向**的霜冻易感与**采摘窗口/调度**；
③ 输出茶农白话的**"今天该采、该防、该灌"**行动建议。官方预警仍是最高权威。

**Q2. 为什么用 GBDT，而不是更大的深度模型？**
A：样本是**逐日气候序列**、特征工程明确、可解释性要求高；GBDT 在中小数据上稳定、可审计、能在 CPU 上跑（生产零 GPU 依赖）。深度模型我们也在问答侧用了（自训 ONNX 意图 + 可选 LoRA 生成），但**数值结论始终来自可审计的模型与规则**。

**Q3. AUC 0.998 是不是夸大？**
A：不是"真实灾害准确率"。它是**对专家规则弱标签的复现度**（留出年 2024–2025，AUC 0.998/F1 0.85，单阈值基线 0.78/0.50）。我们**明确标注为弱标签**，主效果指标改用提前期 MAE、POD/FAR/CSI 等可核验指标。首页也不把 AUC 当主结论。

## 数据与可靠性
**Q4. 数据来源权威吗？**
A：气象历史用 **Open-Meteo ERA5**（再分析，CC BY 4.0），预报用 **MET Norway**（双源互备）；遥感用 **NASA GIBS MODIS NDVI** 与 **Sentinel-2**（STAC 场景）；地形用 **Copernicus DEM**（Open-Meteo Elevation）。全部公开、免密钥，并记录**上游 URL / 参数 / 完整 SHA-256 / 抓取时间**（可比对复现）。

**Q5. 上游限流或断网怎么办？**
A：预报主源用 MET Norway 规避 Open-Meteo 免费档的共享出口 429；archive 失败**回退本地缓存**（缓存也持久化到 Postgres，跨实例轮换不丢）；问答在数据超 60 分钟时**降级为"核验后再行动"**，`decision_ready` 会置 false。

**Q6. 数据过期时还会给确定建议吗？**
A：不会。行动类回答会自动加"⚠️ 数据约 N 分钟前获取（可能过期），请先核验最新预报"并弱化行动动词；信息类（模型/来源）不加此提示。

## 准确性与泛化
**Q7. 模型会不会过拟合？**
A：按**留出年**（2024–2025）评估，不是随机划分；做了置换重要性、单阈值基线与持续法对照；弱标签本身限制了上限，因此我们同时用**提前期误差**与**事件级 POD/FAR/CSI** 交叉验证。

**Q8. 真实田间准确性如何证明？**
A：目前还**没有**田间真值。已有：春霜 357 天 vs ERA5（Tmin MAE 1.32℃，CI 1.21–1.43；持续法 2.08℃），事件级 POD 0.709/FAR 0/CSI 0.709，事件回测 7/7。下一步：**冻结预报版本 + 地块级传感器 + 正/负田间记录**做盲测。

**Q9. 传感器数据与模式估计冲突时信谁？**
A：**现场传感器优先**用于校准与偏差订正（我们已有台站订正模块）；模式估计只作背景。页面对"模式估计 / 台站观测 / 遥感反演 / 现场探头"**分开标注**，不混用。

## 落地与价值
**Q10. 商业模式可持续吗？**
A：B2B2C：合作社/茶企订阅（地块级风险与调度）+ 天气指数保险定价支持 + 政府/园区采购。数据全部公开免费，成本主要在算力（可 CPU 运行，边际成本低）。

**Q11. 预期价值？**
A：以示意测算，亩产值与期望损失给出**减损价值**区间；天气指数保险按客观指数自动理赔。价值核心是**把"看天吃饭"变成可提前 1–7 天行动**。

**Q12. 90 天验证计划？**
A：选 3–5 户茶园，冻结预报版本、记录地块级温湿度与正/负田间记录，按提前期分层报告漏报率，并复校阈值。

## 合规与边界
**Q13. 隐私与数据合规？**
A：传感器上报走 HMAC 签名 + nonce 防重放；众包/结果数据仅存必要字段；只读展示不含隐私；不采集个人信息。

**Q14. 与商业天气 App 的差异？**
A：通用 App 给"城市天气"，我们给**梅家坞地块级的复合茶事行动**，且结论可追溯到数据版本与参数。

**Q15. 现在能直接用来指导生产吗？**
A：**不能无人审核地直接执行**。它是**决策辅助**，必须结合田间实勘与官方预警；这也是我们反复强调的边界。
