# 传感器数据接入（端口设计）

> 目的：让第三方硬件（ESP32/树莓派/气象站）**实时上报**现场观测，进入 TeaWindow 数据流，
> 用于**地块级校正**与观测-网格对比。

## 一、接口
| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/api/sensor` | `X-Sensor-Token` | 上报**单条**观测 |
| POST | `/api/sensor/batch` | `X-Sensor-Token` | 批量（≤500 条） |
| GET | `/api/realtime` | 公开只读 | 各站**最新值**（仅数值，无隐私），供仪表盘实时刷新 |
| GET | `/api/sensor/latest` | `X-Sensor-Token` | 最近明细（含 note） |

- 令牌：环境变量 `SENSOR_TOKEN`（未设置时回退 `ADMIN_TOKEN`）。
- 限流：`/api/sensor` 默认 120 次/分/IP；`/api/realtime` 60 次/分/IP。

## 二、字段与校验
| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| station_id | ✅ | `[A-Za-z0-9_-]{1,40}` | 站点编号 |
| ts | ✅ | ISO8601 | 观测时间（建议带时区 +08:00） |
| temp |  | -30~60 | 气温 ℃ |
| rh |  | 0~100 | 相对湿度 % |
| soil_moisture |  | 0~1 | 土壤体积含水 |
| soil_temp |  | -30~60 | 土壤温度 ℃ |
| precip |  | 0~500 | 降水 mm |
| wind |  | 0~80 | 风速 km/h |
| light |  | 0~200000 | 光照 lux |
| vpd |  | 0~10 | 饱和水汽压差 kPa（可选） |
| note |  | ≤200字 | 备注（仅管理员可见） |
> 至少提供一项测量；非法 `station_id`/`ts`/越界数值/**超前 2 天以上** → **422**；无令牌 → **403**。

## 三、示例
```bash
curl -X POST https://teawindow.onrender.com/api/sensor \
  -H "X-Sensor-Token: $SENSOR_TOKEN" -H "Content-Type: application/json" \
  -d '{"station_id":"MJW01","ts":"2026-10-13T08:00:00+08:00","temp":16.1,"rh":70,"soil_moisture":0.31}'
```
ESP32（ESPHome/MicroPython）伪代码：POST 到 `/api/sensor`，headers 带 `X-Sensor-Token`，body 同上。

## 四、实时闭环
1. 设备上报 → 写入 **SQLite**（`src/store.py`，`data/teawindow.db`）；以 `(station_id, ts)` 为主键**幂等去重**（重复/重放不重复入库），并记录服务器接收时间 `received`；
2. `GET /api/realtime` 汇总各站**最新值**（公开只读）；
3. 仪表盘「现场传感器（实时观测）」面板**每 20 秒**自动刷新（`web/sensor.html` 亦可）；
4. `src/sensor_hub.py` 按 **站点×日** 聚合 → 计算农业气象指标（霜冻/高温/干旱），输出 `data/processed/sensor_indices.csv`，用于与 ERA5 对照及后续**偏差校正**。

> 说明：免费托管实例磁盘可能短暂（重新部署会重建），因此 SQLite 保证**单实例内持久与去重**；生产建议接外部数据库/时序库并加账号与审计。

## 五、安全与合规
- 写接口需令牌 + 限流（仅请求头，禁止 URL 查询参数）；读取最新值公开但不含 `note`（无隐私）。
- 仅存数值观测，不采集个人身份信息；`data/teawindow.db` 与 `data/points/` 已 gitignore。
- **幂等/防重放**：`(station_id, ts)` 唯一；**设备时间漂移**超 2 天拒绝。
- 生产建议：账号/设备白名单、请求签名、外部时序数据库与审计。
