# 路线图（Roadmap）——把短板变加分项

> 借鉴同类获奖方向，规划低成本、可讲述的下一步（部分仅需路线图，不需立即实现）。

## 1. 采集端：高光谱 / 无人机（对标挑战杯获奖"飞采云茶"）
- **思路**：无人机 + 多/高光谱识别嫩芽、病虫害与胁迫，补充"地块级"观测。
- **我们的增量**：把无人机影像与**气象复合风险**融合 → 从"看得到"到"**判得到、排得出**"。
- **成本**：租用/合作无人机 + 公开光谱方法；先做**离线样例**验证。

## 2. 数据端：卫星遥感产融/风控（对标网商银行"大山雀"数字乡村获奖）
- **思路**：用 Sentinel-2 时序 + 地块风险，支持**授信/保险/风控**的地块级评估。
- **我们的增量**：风险指数 → **作物生长与损失代理指标**，服务金融机构。
- **落地**：与农险/农村金融合作试点。

## 3. 模型端：真实标签与主动学习
- **思路**：通过官方"场景单位对接"与**众包上报**（已做 N4）积累真实开采/受灾标签。
- **动作**：把弱标签逐步替换为**真监督**；用主动学习优先标注高不确定样本。

## 4. 产品端：语音 / 微信生态
- **思路**：把 LLM 问答（N3）接入**微信小程序/服务号 + 语音**，降低老年用户门槛。
- **动作**：语音播报每日建议；一键上报（N4）。

## 5. 规模化：多产区复制
- **思路**：换坐标与作物参数即可迁移（其他龙井/绿茶、乃至其他特色农业）。
- **动作**：参数化配置 + 区域模板；先复制到 1–2 个邻近产区。

## 6. 保险端：指数保险产品化（已做 N6）
- **动作**：与保险/政府共建**地块级指数保险**，支持差异化定价与自动理赔。

> 说明：1–2 为**关联获奖方向**的延伸；3–4 直接补"弱标签/体验"短板；5–6 拓展市场与规模。
> 本页用于路演与项目说明，体现**可持续与可扩展**（对齐"市场可持续 15% + 扩展性 10%"）。
