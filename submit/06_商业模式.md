# 商业模式（一页）

> 目标：说清"**谁付钱、付多少、为什么长期用**"（对冲评审"市场可持续性 15%"）。
> 定价均给**市场锚点与来源**；本项目成本天然极低（数据全公开、模型纯 numpy）。

## 1. 价值主张
把分散的气象/遥感信号，变成茶农"**今天该采、该遮阳、该灌溉还是该防冻**"的可执行建议；
对合作社/茶企是**品质与风险管理的数字工具**；对保险/政府是**风险识别与减损服务**。

## 2. 客户与付费方
| 角色 | 需求 | 是否付费 |
|---|---|---|
| 个体茶农 | 风险提示 + 采摘窗口 | 免费为主（获客） |
| 合作社/大户 | 多地块管理、鲜叶调度 | **付费主力** |
| 茶企/品牌 | 品质稳定、溯源协同 | **付费主力** |
| 农险公司 | 风险识别/减损、指数产品 | **合作/授权** |
| 政府（农业/气象） | 公共服务、防灾 | **项目采购** |
| 数字农业服务商 | 能力嵌入 | **API 授权** |

## 3. 成本结构（关键优势：近乎零变动成本）
| 项 | 说明 | 估算 |
|---|---|---|
| 数据 | Open-Meteo / NASA / Meteostat / S2，全部公开免费 | **￥0** |
| 算力 | 纯 numpy（本机/边缘可跑） | 免费层 ￥0，或低配 ￥0–200/月 |
| LLM | DeepSeek 按量；每户每日 1 条建议 | ≈ ￥0.01–0.05/户/日 |
| 运维/人力 | 2 人（竞赛阶段） | 时间成本 |

## 4. 定价方案（锚定市场价，含依据）
**A. 茶农个人版**：免费（1 地块，基础风险+建议）→ 获客与口碑。

**B. 专业版（茶农/小户）**：**￥299–999 / 户 / 年**
- 依据：农业 SaaS 基础版"每个用户几百到几千元"（36氪企服点评）。

**C. 合作社 / 茶企版**：**￥1 万–5 万 / 年**（按地块数/产值）
- 依据：农产品溯源系统"中小企业 1万–2万，大型 5万–30万"（观麦科技）；
  茶园管理系统采用"**首年 + 逐年续费**"模式（deerpu 线上茶园管理系统）。

**D. 保险 / 数据合作**：**￥2 万–10 万 / 年**（风险指标授权、减损服务）
- 依据：茶叶种植保险"**每亩保额 500 元、费率 2%、保费 10 元**"，
  倒春寒霜冻**每亩赔 1600 元**、茶树死亡**每亩 5000 元**（丽水松阳/莲都案例，深蓝保）；
  农业气象巨灾指数保险由**政府投保、保额 2000 万**（莆田案例）。
  —— 我们可帮助识别高风险地块，服务保险定价与减损。

**E. 政府项目采购**：**￥5 万–30 万 / 项目**（区域平台/科普/防灾）
- 依据：一套智慧农业系统"基础通常在几千到几万美元"（搜狐/行业报道）。

## 5. 收入来源与单位经济
- 收入：订阅（B/C）+ 合作授权（D）+ 项目（E）。
- 盈亏平衡示例：若年固定成本约 **￥2,000**（低配托管 + LLM），
  则 **3–7 个专业版用户（￥300–700/户）即可覆盖**；合作社版 1 单即显著盈利。
- 扩展：换坐标/参数即可复制到其他龙井/绿茶产区 → 摊薄研发成本。

## 6. 落地路径（分阶段）
1. **0–90 天（竞赛期）**：免费服务梅家坞 3–5 户，拿到验证与口碑。
2. **3–6 个月**：与 1–2 家合作社/茶企签约试点（B/C）。
3. **6–12 个月**：对接农险/溯源/数字农业平台（D 授权）。
4. **12 个月+**：申报区/市级数字农业项目（E），并向其他产区复制。

## 7. 竞争壁垒与风险
- **壁垒**：地块级复合风险算法 + 免费数据 + 低边际成本 + 已开源可复现。
- **风险**：① 官方气象服务已覆盖部分功能 → 走"地块级+可行动+闭环"差异化；
  ② 茶农付费意愿低 → 以合作社/茶企/保险为主付费方；
  ③ 免费层休眠/成本 → 采用静态页 + 外部定时刷新（见 `.github/workflows/refresh.yml`）。
