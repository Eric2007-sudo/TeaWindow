# 评估整改说明（对应《产品测试与评估报告》）

> 依据：`TeaWindow产品测试评估报告.md`。本文件记录**第一阶段（"不会误导、不被滥用"）**的整改结果。

## 已修复（本轮）
| 报告问题 | 整改 | 验证 |
|---|---|---|
| **P0-4 过期日期** | 调度/决策/采摘窗口统一 `date >= 今天` 过滤；不再推荐过去日期 | `best_pick_day == pick_window[0]`；调度首日≥今天 |
| **P0-1 LLM 与结构化数据冲突** | ① **日报建议改用自研规则生成**（与适宜度/风险严格一致，消除"适宜度0却说适合采"）；② LLM 增强改为**只润色、禁改数值**，输出后做**数值一致性校验**，失败**回退规则** | 10-19 建议=“防连阴雨/排水…适宜度0”；10-22=“适合采” |
| **P0-2 refresh 无鉴权** | `/api/refresh` 需 **`ADMIN_TOKEN`**（未设置则 403） | 线上无 token→403 |
| **P0-3 存储型 XSS** | `report.html` 改 `textContent`、移除公开读取；服务端对 `kind` 枚举、`date` 日期、长度**强校验**；全站加 **CSP** | 非法 kind/date → 422 |
| **P1-1 无拒识/越界** | 空问题→澄清；**英文**→中文提示；**医疗/金融等越界**→边界说明；**三个月预测**→说明仅 16 天+气候概率；低置信→澄清 | 6 类边界用例全部正确 |
| **P1-2 无配额/成本保护** | `/api/ask` **限流**（默认 40 req/min/IP，可配）；`/api/reports` 需 admin；`engine` 非法→422 | ask 限流、reports 403、engine 非法 422 |
| **P1-3 安全头缺失** | 增加 **CSP / HSTS / X-Content-Type-Options / X-Frame-Options / Referrer-Policy** | 响应头已带 CSP、nosniff |
| **P1-4 指标过度表达** | 首页核心 KPI 的 **AUC 已移除**（改为"今日行动建议"）；指标面板标注 **"弱标签复现指标，不代表真实灾害预测准确率"** | 见仪表盘 |
| **P1-7 保险/价值过度外推** | 保险面板标 **"概念验证，非产品报价"**；说明 ¥10(补贴政策保费) 与 ¥1000(精算公平保费) **口径不同不可直接比较** | 见仪表盘/报告 |
| **P1-6 物候基线** | 已如实表述"与固定日期基线相当" | `report/phenology_validation.md` |

## 待办（第二阶段，需真实数据/资源）
- **P1-5 / 真实性**：预注册事件清单、**加入负事件与盲测**、滚动历史预报回放；报告事件级 **precision/recall、误报天数、有效提前量**。（工具位：`report/` + `research/`）
- **真实田间验证**：真实地块多边形、传感器一季布点、逐地块校准与留站验证；
- **账号体系**：合作社/角色权限、地块归属、写操作身份与审计；
- **移动端**：预报表改"一天一卡"（当前已过滤过期并简化）；
- **季节/农艺约束**：非采摘季关闭采摘推荐，改养护建议。

## 说明
- 生成式问答（1.5B + 事实约束解码 + 回退）在本地/GPU 端已验证；生产仍用**自研规则引擎**（更稳、可审计）。
- 欢迎以"数据过期时不建议、无法判断时敢说不知道、每个数字有明确时间尺度"为验收标准继续复测。
