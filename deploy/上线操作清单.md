## A. Cloudflare Pages 直传（最快，约 5 分钟，得永久公网链接）

1. 打开 https://dash.cloudflare.com/ → 注册/登录（免费）。
2. 左侧 **Workers & Pages** → **Create** → **Pages** → **Upload assets**（Direct Upload）。
3. 项目名随意，如 `teawindow`；点 **Create project**。
4. 把本地 **`web` 文件夹**里的 **全部文件**（`index.html`、`app.js`、`data.js`、`chart.umd.min.js`）拖进去（**注意：拖内容，不是拖 `web` 文件夹本身**）。
5. 点 **Deploy site** → 得到链接：`https://teawindow.pages.dev`。
6. 用手机打开该链接，确认页面正常（离线数据已内嵌，无需后端）。

> 更新数据：重跑 `python src\pipeline.py`，再重复第 4 步重新上传即可。

## B. GitHub Pages（已配好自动部署）

### B1. 建仓库并推送（命令行，复制即用）
```powershell
cd "D:\college\大二上\双创启蒙\AI4Climate-梅家坞研究\TeaWindow"
git init -b main
git add .
git commit -m "TeaWindow: Meijiawu compound climate risk & picking-window assistant"
# 在 github.com 新建一个空仓库（不要勾选 README），假设名为 TeaWindow
git remote add origin https://github.com/<你的用户名>/TeaWindow.git
git push -u origin main
```
> 若用 `gh`：`gh auth login` 后 `gh repo create TeaWindow --public --source=. --push`。

### B2. 开启 Pages
1. 仓库 → **Settings** → 左侧 **Pages**。
2. **Build and deployment** → Source 选 **GitHub Actions**。
3. 本仓库已含 `.github/workflows/pages.yml`，推送后会自动部署（见 **Actions** 标签页）。
4. 完成后链接形如：`https://<用户名>.github.io/TeaWindow/`。

> 说明：工作流把 `web/` 目录作为站点发布，因此无需后端，双击/访问即用。
> 更新数据：重跑 `pipeline.py` → `git add web && git commit -m update && git push`。

## C. Render 实时服务（FastAPI，含每日自动刷新）

1. 先完成 **B1**（把代码推到 GitHub）。
2. 打开 https://render.com/ → 注册/登录（可用 GitHub 账号）。
3. **New** → **Web Service** → 选择你的 `TeaWindow` 仓库。
4. 配置（通常会被 `deploy/render.yaml` 自动识别，若未识别则手动填）：
   - **Runtime**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn src.serve:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: Free
5. 环境变量（可选，用于真实 LLM 建议）：**Environment** → Add → `DEEPSEEK_API_KEY` = `sk-xxxx`。
6. **Create Web Service** → 等待构建完成 → 得到链接：`https://teawindow.onrender.com`。
7. 验证：访问 `/api/health`、`/api/summary`，或直接打开首页（会自动读 `/api/overview`）。
8. 定时刷新已内置（`serve.py` 中每日 **06:00 Asia/Shanghai** 自动跑管线）。

> 免费层休眠说明：长时间无访问会休眠，首次访问需 ~30 秒唤醒。
> 另一键方式：仓库含 `render.yaml`，可在 Render 用 **Blueprint** 一键创建。

## 常见问题

| 现象 | 处理 |
|---|---|
| Pages 打开是 404 | 确认拖入的是 `web/` 内**文件内容**（最外层应是 `index.html`） |
| 页面图表空白 | 确认 `chart.umd.min.js`、`data.js`、`app.js` 三个文件都在同一层 |
| Render 构建失败 | 确认仓库根目录含 `requirements.txt`；Start 命令拼写正确 |
| 建议显示"规则模板" | 未配置 `DEEPSEEK_API_KEY`（属正常降级），配置后重跑管线即为 DeepSeek |
| 想让数据每日更新（静态页） | 每天重跑 `pipeline.py` 并重新上传/提交一次 |
| 中文路径报错 | 本项目相对路径均安全；如需绝对避免，可整体拷到纯英文路径再跑 |
