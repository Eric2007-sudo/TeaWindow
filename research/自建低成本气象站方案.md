# 自建低成本气象/土壤传感器方案（产出真正的一手数据）

> 目标：不依赖任何人，自己产出一手微气候数据（温湿度/土壤/光照），
> 放到茶园、阳台或楼顶均可；用 `src/sensor_ingest.py` 即可接入模型管线。

## 一、采购清单（约 ￥200–600）
| 部件 | 型号示例 | 作用 | 约价 |
|---|---|---|---|
| 主控 | ESP32 / ESP8266 | 采集+联网 | ￥20–40 |
| 温湿度气压 | SHT31 / BME280 | 气温、湿度、气压 | ￥15–30 |
| 土壤 | 电容式土壤湿度(SEN0193) + DS18B20 | 土壤水分/温度 | ￥20–40 |
| 光照 | BH1750 | 光照强度 | ￥8–15 |
| 供电 | 18650 + TP4056 或 5V 太阳能板 | 户外供电 | ￥30–80 |
| 外壳/线材 | 防水盒、杜邦线 | 防护 | ￥30–60 |
| 联网 | WiFi(免费) 或 4G(SIM+模块) | 回传 | ￥0–150 |

## 二、固件（两选一）
- **ESPHome**（推荐，YAML 配置，免写代码）：支持上述传感器，自动上报。
- **Arduino/MicroPython**：自写，POST 到你自己的接口。
- 回传目标可先用**免费 MQTT（如 EMQX/HiveMQ 公共 broker）或一个在线表格/云盘**先落地。

## 三、部署要点
- 位置：距地面 1.5m 的百叶箱/遮阳罩内测温湿度；土壤探头插入 10–20cm。
- 频率：每 10–30 分钟一条；**重点保底**：日最低温（防霜冻）、日最高温（防高温）。
- 地点选择：优先**低洼/北坡（更易霜冻）** 与 **坡顶（更易高温）** 各一个，形成对比。
- 不要求核心产区：**阳台北坡的对照数据同样有价值**（微气候比较）。

## 四、数据落地与分析
- 把导出的 CSV 存成列：`date,tmin,tmax,tmean,precip,rh`（至少前四个）。
- 运行：
```powershell
python src\sensor_ingest.py 你的数据.csv data\processed\sensor_indices.csv
```
- 脚本会计算有效积温/霜冻/倒春寒/高温/干旱等指标，可与模型结果对照。

## 五、7 天可完成的里程碑
| 天 | 事项 |
|---|---|
| D1 | 下单 + 选点（低洼/坡顶各一） |
| D2–3 | 组装 + 刷 ESPHome，联 WiFi |
| D4 | 上线采数，核对与手机天气 App 差异 |
| D5–7 | 连续采数，导出 CSV → 跑 `sensor_ingest.py` |

## 六、合规
- 只在自有/获许可的场地部署；不采集个人隐私；数据展示去标识化。
