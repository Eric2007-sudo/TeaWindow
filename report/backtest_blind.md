# 事件级回测 + 负事件 + 误报/提前量（滚动历史回放）

> 真值仍为**规则弱标签**；本报告区分『规则复现指标』与『业务指标』，并**加入负事件**给出误报率。
> 判定：窗口内出现风险日(risk_R≥0.5)即判命中；提前量=事件前 3 天内首次出现 risk_R≥0.3 的天数。

## 3) 误报代理（全期）
- 全期风险日基准率（risk_R≥0.5 占比）= **7.9%**（339/4301 天）。
- 落在**文档化事件窗口内**的风险日：66；**窗口外**：273。
- 说明：**窗口外 ≠ 必然是误报**（可能存在未文档化的真实风险），故称『误报代理』。
## 4) 结论（诚实）
- 本框架把『规则复现』与『业务验证』分开：事件召回高属预期；**关键待补是与真实受灾/减产/品质的对照**。
