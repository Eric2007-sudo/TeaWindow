# D2T 生成模型实验（M2–M3）与结论

> 目标：用我们自建数据训练"结构化事实→自然回答"的小型生成模型（A+C 中的 C）。
> 结论：**生产引擎保留 L1 规则**；0.5B 生成模型质量**不达标**，记为实验与后续方向。

## 1. 数据集（M2）
- `src/qa/build_d2t.py` 合成 **chat 格式**样本：`{系统, 用户=问题+事实JSON, 助手=自然回答}`。
- 规模：**train 3240 / eval 360**（15 类意图 × 多变体措辞 × 随机数值）。

## 2. 训练（M3，GPU 8×4090，`~/teacloud`）
- 基座：**Qwen2.5-0.5B-Instruct**；全参微调，bf16，3 epochs。
- 训练 loss：0.343 → 0.029 → **0.023**；产物 `~/teacloud/models/qa_d2t`。
- 训练集内样本生成与目标高度一致（见下）。

## 3. ONNX 导出
- `gpu/export_onnx.py`（optimum）导出 **fp32 ONNX（约 1.4G）成功**；int8 量化产物异常（权重外置未随附，5.5K）。
- 体积不适配 Render 免费层；按既定策略 **Render 用 L1 规则**，生成模型仅本地/GPU 端。

## 4. 生成质量（关键，诚实）
- **同分布样本**（训练/评测集）：与目标基本一致。
- **分布外问法**（见 `infer_d2t.py`）出现**事实性错误**：
  - "要不要防冻"（事实：无霜冻）→ 答成"**要防冻**…越冬"（错）。
  - "今年什么时候开采"（事实 2026-03-16）→ "约 1.8 天"（错）。
  - 保险/损失：数值错配。
- 原因：**0.5B 容量不足 + 数据/对齐有限**；小模型在事实约束与数值保持上不可靠。

## 5. 决策
- **生产（Render/离线）使用 L1 自研规则引擎**（可靠、接地、含来源链）。
- 生成模型标记为**实验/GPU 演示**；后续方向：**(a) 更大基座（1.5B–7B）+ 更多数据 + 事实约束解码**；**(b) 只做"润色"**（保留 L1 事实，模型仅改写措辞，降低事实风险）；**(c) 校验层**（生成后与事实比对，不一致则回退 L1）。
- DeepSeek 仍仅作**可选润色**。
