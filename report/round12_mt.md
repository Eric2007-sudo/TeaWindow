# 第十二轮：LLM 对话训练 + 记忆窗口（≈10 条）

> 目标：参考开源/业界多轮对话做法，改善互动体验；并用 GPU 训练提升多轮接地。
> 依据调研：多轮难点=连贯性/上下文管理（滑动窗口、摘要、记忆增强）；训练=**messages(ShareGPT) 格式 + 仅 assistant 掩码的 LoRA/QLoRA**；评测=整段或滑动窗口。

## 一、记忆窗口与上下文（工程，已上线）
- **记忆窗口 ≈10 条消息**：`/api/ask` 取 `history[-10]`；`AskReq.history` 上限 24 条。
- **滚动摘要**：前端把窗口之外较早的用户轮次压缩为 `state.summary`（≤220 字）随请求发送；引擎在"追问/指代"时用它补上下文。
- **会话本地持久化**：`chat.js` 用 `localStorage` 保存最近 20 条消息与 state，**刷新不丢**（清空对话框一并清除）。
- **对话记忆问答**："刚刚我问了什么 / 你的上一条回答是什么" 直接作答（无历史→"第一轮"，有摘要→引用摘要）。
- 证据：`test_memory_questions`、`test_rolling_summary_memory`、`test_followup_relative_day_not_overridden`。

## 二、多轮对话 GPU 训练（LoRA）
- 数据：`src/qa/build_multiturn.py` 生成 **messages 多轮**样本（同一事实/目标日贯穿 2–3 轮，含追问/指代/改口）；**train 3600 / eval 400**。
- 训练：`gpu/train_lora_multiturn.py` —— PEFT **LoRA**（r=16, α=32）微调 `Qwen2.5-0.5B-Instruct`，**仅 assistant 段计 loss**，2 epochs，**可训参数 1.75%**。
- 评测（多轮接地度=多轮事实数字在末轮回答中原样出现率）：

| 指标 | 数值 |
|---|---|
| 底座 Qwen2.5-0.5B | **0.691** |
| **LoRA（多轮）** | **0.849（+15.8pt）** |

- 结论：LoRA 显著提升多轮接地；**生产默认仍用自研规则引擎**（可审计），生成模型作为可选增强（GPU/本地）。

## 三、与自适应交互的关系
