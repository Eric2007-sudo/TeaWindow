# 第十四轮：第七轮评测整改

> 依据：`TeaWindow产品第七轮全面复测报告_2026-10-14.md`（84/100）。测试：**111 passed**。

## 一、P0 整改
1. **刷新闭环**：`refresh_state` 增 `last_error/next_retry`；成功/失败均记录；外部工作流 `refresh.yml` 改为**每 3 小时**（与内置 3h 对齐，免费层休眠时保底），使 `last_success` 持续更新。
2. **陈旧数据降级**：数据年龄 >60 分钟时，所有行动类回答**前置"可能过期"提示并弱化行动动词**（如"建议灌溉"→"核验后再考虑灌溉"、"建议先测量根层墒情"→"请先测墒并核验最新预报后再决定"），来源链标注"时效: 数据可能过期(降级为核验)"。
3. **就绪语义拆分**：`/api/ready` 返回 `service_ready`（进程/路由可用）与 **`decision_ready`**（非陈旧 + 血缘 + 刷新非未知/失败 + **漂移检查通过**）；`deploy_check` 用 `service_ready`。
4. **格式+日期跨轮**：JSON/表格**继承 `state.format/fields/active_date`**；"10-20 五字段 → 下一天也用相同字段" → **10-21 且同五字段**；表格列按用户字段渲染。
5. **最后改口优先**：`取消/不要/不再/算了 + 关键词` → **REMOVE** 对应任务（并从 state.tasks 删除），新指令 ADD；"取消排水，改为灌溉"不再出现排水。
6. **部署上线最新 SHA**：推送后触发部署并校验在线 build。

## 二、P1 整改
- **相对日期**：最长词优先（大后天>后天>明天）；纯相对日期追问强制按日回答（"大后天呢"→今天+3）。
- **运维问答接入**：血缘/版本（URL/参数/SHA/构建）、**验证历史（不足两次时诚实说明）**、告警与投递记录、漂移阈值指引。
- **可信度问答**："这个数据可信吗/可靠吗" → 可信度说明（来源性质/不确定性/非正式预警），不再被追问劫持。
- **前端**：欢迎消息仅在无历史时显示（不再追加到恢复历史末尾）；主页标题动态"未来 N 天"。
- **测试幂等**：nonce 测试改用随机 UUID，避免跨运行残留导致 CI 重试失败。
