3) 设备接入示例
curl：
curl -X POST https://teawindow.onrender.com/api/sensor \
  -H "X-Sensor-Token: $SENSOR_TOKEN" -H "Content-Type: application/json" \
  -d '{"station_id":"MJW01","ts":"2026-10-13T08:00:00+08:00","temp":16.1,"rh":70,"soil_moisture":0.31}'
ESP32（Arduino/ESPHome）伪代码：
POST /api/sensor
headers: X-Sensor-Token, Content-Type: application/json
body: {"station_id":"MJW01","ts":<当前ISO时间>,"temp":<SHT31温度>,"rh":<湿度>,"soil_moisture":<电容式土壤湿度>}
字段：station_id, ts(ISO8601) 必填；temp/rh/soil_moisture/soil_temp/precip/wind/light 至少一项。校验：station_id 字母数字_-（≤40），数值范围校验。
